Домашнее задание: работа с базой данных school.db

Цель — научиться добавлять, удалять и выбирать данные из базы SQLite, используя основные SQL-команды.

1. Добавление данных

  1. Добавьте в таблицу teachers преподавателя Андрей Кузьмин (кафедра — Физика).
  2. Добавьте в таблицу courses курс Основы физики, ведущий — Андрей Кузьмин.
  3. Добавьте студента Наталья Сергеева, возраст 17.
  4. Запишите Наталью на курс Основы физики (таблица student_course).

Команда для работы с добавлением: INSERT

2. Удаление данных

  1. Удалите из таблицы students студента Дмитрий Орлов.
  2. Удалите из таблицы student_course все записи с курсом История Древнего мира.

Команда для удаления: DELETE
